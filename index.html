LLM report engine: 100K+ evaluations into written reports

The dashboards show the numbers; the next layer writes the story behind them. Schools generate a huge volume of free-text feedback in Danish and English, so I designed a pipeline that turns it into written reports per evaluation, teacher, school and comparison, self-hosted on open models so student data stays private.

  1. 01ResponsesDA / EN free text
  2. 02Token-aware chunkingfits each model's context
  3. 03Maplocal LLM summarises each chunk
  4. 04Reducetoken-aware merge of summaries
  5. 05JSON reportvalidated, stored per entity
  • RAG over fine-tuning, then dropped the vector store once semantic search turned out not to be needed.
  • Token budgets: capped output with max_tokens, prompt-level length targets, and retries on finish_reason.
  • Model choice: Gemma 3 27B, then Qwen3.5-35B-A3B (MoE, 4-bit) for speed on the same hardware.
